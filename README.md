# solo-trip-feeling-share-with-plateau

PLATEAU Hack Challenge 2022 in 大和ミュージアム（呉）にて制作したデモです。

## デモ内容
PLATEAU Hack Challengeは、国土交通省が開発しているPLATEUという日本の3D都市モデルを活用したアイデアとデモの開発を行うハッカソンです。  
私たちのチームは「旅の感動共有アプリ」と題して、AR上で旅の思い出を建物に貼り付け共有するSNSアプリを提案しました。  
UnityとGoogle Geospatial APIを利用し、会場のある呉市のモデルを利用し、建物に文字を貼り付ける様子のARデモの作成まで行いました。
